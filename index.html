Panduan — buat flyer & poster

Gerak isyarat
  • 1 jari pada objek = alih. Tarik kotak sudut = besar/kecil, bulatan atas = putar.
  • 2 jari = cubit untuk zum, seret untuk gerak paparan (sentiasa boleh).
  • Ketuk 2× pada teks = edit tulisan.
  • Ketuk kawasan kosong = nyahpilih.
Resipi flyer 5 minit
  1. Baru → pilih saiz (Story/TikTok 1080×1920, FB 1080×1350, atau A4 300 dpi untuk cetak).
  2. Templat → pilih susun atur, atau Latar → warna / gradien.
  3. Gambar → masukkan produk. Buang Latar → pilih kaedah.
  4. Teks → tulis tajuk. Di Panel › Sifat: fon, saiz, warna, lengkung, garis tepi, bayang.
  5. Panel › Elemen → bentuk, jalur harga, butang. Panel › Lapisan → ▲▼ untuk susun atas/bawah.
  6. Muat turun → PNG (jelas) atau JPG (kecil untuk FB/TikTok).
Cetak DTF
Pilih gambar → Halftone (dalam menu Alat/Panel) → pilih warna baju untuk dibuang → laras saiz dot → Muat turun PNG lutsinar.
